Area, window, or screen

Drag out any area, click a window to grab exactly that window, or click the desktop for the whole screen. Resize with the handles and see the size in pixels.

🖍

Mark it up in place

Pen, line, arrow, rectangle, highlighter, and text, in twelve colors. Scroll to change the thickness while you draw.

😀

Emoji stamps

Pick from smileys, gestures, and symbols like ✅ ⚠️ 🐛. Click to stamp, or drag to make it bigger.

✋

Move anything you've added

Drag text, emoji, arrows, and lines around after you place them. Double-click text to edit it, and ⌘Z undoes it all.

📋

Copy or save, full resolution

Copy straight to the clipboard, or save as PNG or JPEG to a folder you pick in Settings. Retina captures keep every pixel.

Install

Free download for macOS 14 or later on Apple Silicon.

  1. Download Paneless.zip and unzip it.
  2. Move Paneless.app to your Applications folder and open it.
  3. macOS blocks it the first time because it isn't notarized. Open System Settings → Privacy & Security, scroll down, and click Open Anyway.
  4. Allow Paneless under Privacy & Security → Screen & System Audio Recording, then reopen it.

Or from Terminal

curl -L -o /tmp/Paneless.zip \
  https://github.com/MattSheehanDev/paneless/releases/latest/download/Paneless.zip
ditto -x -k /tmp/Paneless.zip /Applications
xattr -dr com.apple.quarantine /Applications/Paneless.app
open /Applications/Paneless.app

Build from source

# xcode-select --install  (if needed)
git clone https://github.com/MattSheehanDev/paneless
cd paneless
make install
